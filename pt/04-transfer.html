Função de transferência

magnitude + fase + coerência
são uma coisa só

Os três juntos ou nenhum.

Transfer function é a comparação matemática entre o que entrou no sistema (sinal do gerador, via loopback) e o que saiu (sinal captado pelo microfone). Tem 3 resultados que precisam ser lidos juntos:

Magnitude:
QUANTO o sistema mudou cada frequência (em dB).
Fase:
QUANTO o sistema atrasou cada frequência (em graus).
Coerência:
QUANTO CONFIÁVEIS são os 2 acima (0 a 1).
✓ Como ativar no OSM
Cmd/Ctrl + 3 abre 3 gráficos lado a lado
Em cada um escolha Magnitude / Phase / Coherence
FFT power 14, LPF 1 Hz padrão pra igreja/sala
Coherence threshold 0.7 esconde dados ruins automaticamente
Magnitude (dB) +10 / 0 / −30
Fase (graus) +180 / 0 / −180
Coerência (0–1) 20 Hz — 1 kHz — 20 kHz
Ordem de leitura na hora de interpretar
1
Coerência
Olhe primeiro. Onde está baixa, ignore os outros 2.
2
Fase
Suave ou decrescente = ok. Saltos abruptos = problema (ou wrap, ver inf. 01).
3
Magnitude
Tendência geral, picos e vales — mas só onde coerência é boa.
