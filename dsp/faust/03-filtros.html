Módulo 03 — Filtros

Filtros: biquad em 1 linha.

No módulo 04 da Trilha DSP a gente implementou biquad em Rust manualmente — coeficientes, formas direta I/II, estabilidade, 80+ linhas. Em FAUST, isso é fi.lowpass(1, freq). Mesmo resultado, 80× menos código.

§ 01

O namespace fi. — filtros prontos.

fi. tem 60+ filtros prontos pra usar. Biquads, butterworths, IIR/FIR, ladder, Moog-style, all-pass, comb, e por aí vai. Aqui foco nos 6 que cobrem 95% dos casos.

FunçãoO que faz
fi.lowpass(N, fc)Passa-baixa de ordem N na frequência fc
fi.highpass(N, fc)Passa-alta de ordem N na frequência fc
fi.bandpass(N, lo, hi)Passa-faixa entre lo e hi
fi.notchw(B, fc)Notch (rejeita-faixa) — pra cortar microfonia
fi.peak_eq(L, fc, B)Peaking EQ: ganho L (linear) em fc, largura B em Hz
fi.low_shelf(L, fc)Low shelf — ajusta tudo abaixo de fc
fi.high_shelf(L, fc)High shelf — ajusta tudo acima de fc
fi.resonbp(fc, Q, G)Bandpass ressonante (síntese, wah)

Em todos: N = ordem (1 = 6 dB/oitava, 2 = 12 dB/oct, 3 = 18, 4 = 24). fc = corner frequency em Hz.

§ 02

Lowpass, highpass, bandpass.

O combo mais usado em qualquer plugin de áudio. Aqui um plugin de "tone shaping" simples — lowpass + highpass com sliders.

tone.dspfaust
declare name "Tone Control";
import("stdfaust.lib");

// Highpass corta o sub-grave inútil. 80 Hz é o padrão pra voz.
hp_freq = hslider("low cut [unit:Hz][scale:log]", 80, 20, 500, 1);

// Lowpass corta o agudo áspero. 12 kHz é razoável.
lp_freq = hslider("high cut [unit:Hz][scale:log]", 12000, 2000, 20000, 1);

// Ordem 2 = inclinação 12 dB/oitava
process = fi.highpass(2, hp_freq) : fi.lowpass(2, lp_freq);

Pluga isso num canal de voz no DAW e você já tem um EQ de canal funcional.

Ordem importa

fi.lowpass(1, fc) tem inclinação de 6 dB/oitava — corte suave, deixa muito passar. fi.lowpass(4, fc) tem inclinação de 24 dB/oitava — corte brusco, "wall". A diferença sonora é grande:

  • Ordem 1: bom pra "tirar o brilho" sem perder ar.
  • Ordem 2: padrão analógico clássico.
  • Ordem 4: corte cirúrgico, usado em crossovers.
§ 03

Peak EQ e shelf.

Pra EQ paramétrico, você precisa de peaking EQ (sino: boost/cut em torno de uma freq) e shelves (sapata: boost/cut em tudo acima/abaixo).

peaking.dspfaust
declare name "Peak EQ";
import("stdfaust.lib");

freq = hslider("freq [unit:Hz][scale:log]", 1000, 20, 20000, 1);
gain_db = hslider("ganho [unit:dB]", 0, -18, 18, 0.1);
bw   = hslider("largura [unit:Hz]", 500, 50, 5000, 10);

gain_linear = gain_db : ba.db2linear;

process = fi.peak_eq(gain_linear, freq, bw);

Esse plugin tem 3 sliders: frequência, ganho, largura. É um EQ paramétrico de 1 banda. Multiplicar isso por 3 e você tem o de 3 bandas (que vamos fazer no fim do módulo).

§ 04

Biquad direto (fi.tf2).

Os fi.lowpass, fi.peak_eq, etc. são wrappers que calculam coeficientes biquad internamente. Se você quer controle total sobre os coeficientes (b0, b1, b2, a1, a2), usa fi.tf2:

biquad diretofaust
import("stdfaust.lib");

// Coeficientes do biquad — você calcula via cookbook RBJ ou outro método
b0 = 0.1;  b1 = 0.2;  b2 = 0.1;
a1 = -1.4; a2 = 0.5;

// Transfer function de 2a ordem
process = fi.tf2(b0, b1, b2, a1, a2);

Útil quando você implementou um filtro custom no módulo 04 da Trilha DSP em Rust e quer "traduzir" — só copia os coeficientes pro fi.tf2 e funciona.

EQ Cookbook

O EQ Cookbook em português (tradução do RBJ Cookbook) tem todas as fórmulas pra calcular b0…a2 de qualquer filtro biquad. Se você sabe os coeficientes, fi.tf2 é seu amigo.

§ 05

Rust manual vs FAUST — o mesmo lowpass.

Comparação direta. Mesmo filtro (lowpass biquad ordem 2, fc=1000 Hz), duas implementações.

Rust manual (do módulo 04 da Trilha DSP)

biquad.rsrust
struct Biquad {
    b0: f32, b1: f32, b2: f32,
    a1: f32, a2: f32,
    x1: f32, x2: f32,
    y1: f32, y2: f32,
}

impl Biquad {
    fn lowpass(fs: f32, fc: f32, q: f32) -> Self {
        let w0 = 2.0 * std::f32::consts::PI * fc / fs;
        let cos_w0 = w0.cos();
        let alpha = w0.sin() / (2.0 * q);
        let a0 = 1.0 + alpha;
        Biquad {
            b0: (1.0 - cos_w0) / 2.0 / a0,
            b1: (1.0 - cos_w0) / a0,
            b2: (1.0 - cos_w0) / 2.0 / a0,
            a1: -2.0 * cos_w0 / a0,
            a2: (1.0 - alpha) / a0,
            x1: 0.0, x2: 0.0, y1: 0.0, y2: 0.0,
        }
    }

    fn process(&mut self, x: f32) -> f32 {
        let y = self.b0 * x + self.b1 * self.x1 + self.b2 * self.x2
              - self.a1 * self.y1 - self.a2 * self.y2;
        self.x2 = self.x1; self.x1 = x;
        self.y2 = self.y1; self.y1 = y;
        y
    }
}

FAUST

lowpass.dspfaust
import("stdfaust.lib");

process = fi.lowpass(2, 1000);
Quando cada um

FAUST pra prototipar rápido, gerar plugin, validar sonoridade, iterar com cliente. Rust pra quando você quer otimizar pra um caso muito específico, integrar com outro sistema, ou aprender o que tá por baixo. A FAUST gera Rust otimizado — então no fim do dia, o plugin que toca também é Rust (compilado pela FAUST).

§ 06

Aplicação: EQ paramétrico de 3 bandas.

EQ útil pra mixagem de voz, instrumento ou bus master. Low shelf + peak EQ + high shelf, cada um com freq e gain ajustáveis.

eq3.dspfaust
declare name "EQ Paramétrico 3 bandas";
declare author "Jefferson Cunha";
import("stdfaust.lib");

// LOW SHELF — abaixo de 250 Hz (típico)
low_freq = hslider("low/freq [unit:Hz][scale:log]", 100, 20, 500, 1);
low_gain = hslider("low/ganho [unit:dB]", 0, -18, 18, 0.1) : ba.db2linear;

// MID — peak EQ paramétrico
mid_freq = hslider("mid/freq [unit:Hz][scale:log]", 1000, 200, 8000, 1);
mid_gain = hslider("mid/ganho [unit:dB]", 0, -18, 18, 0.1) : ba.db2linear;
mid_bw   = hslider("mid/largura [unit:Hz]", 500, 50, 5000, 10);

// HIGH SHELF — acima de 5 kHz
high_freq = hslider("high/freq [unit:Hz][scale:log]", 8000, 2000, 20000, 1);
high_gain = hslider("high/ganho [unit:dB]", 0, -18, 18, 0.1) : ba.db2linear;

eq_mono = fi.low_shelf(low_gain, low_freq)
        : fi.peak_eq(mid_gain, mid_freq, mid_bw)
        : fi.high_shelf(high_gain, high_freq);

// Stereo — aplica nas duas vias
process = eq_mono , eq_mono;

Compila no editor.faust.grame.fr e olha o UI — 7 sliders organizados em grupos "low", "mid", "high" automaticamente (porque você usou o prefixo no label).

Pronto pra exportar

Esse EQ funciona. Quando você for pro Módulo 08 e exportar como VST, vai poder usar no Reaper, EQ-ar a voz do pregador, salvar como preset. Plugin de produção, em ~25 linhas.
