§ 01

A convenção freq/gain/gate.

FAUST não tem um "evento MIDI" no DSP — em vez disso, o plugin define 3 sliders especiais: freq (frequência da nota), gain (velocity), gate (1 quando tecla pressionada, 0 quando solta). O wrapper VST conecta MIDI nesses 3.

Reconhecimento é por label:

Label do sliderO que recebe via MIDI
"freq"frequência da nota tocada (Hz) — derivada do MIDI note number
"gain"velocity normalizada (0 a 1)
"gate"1 = nota on, 0 = nota off
Por convenção, não por mágica

O wrapper procura sliders com exatamente esses labels (case-sensitive). Se você escrever "Freq" ou "frequência" não vai funcionar. Use "freq", "gain", "gate".

§ 02

declare options "[nvoices:8]".

Pra ativar polifonia, o plugin precisa anunciar quantas vozes simultâneas suporta. Isso é feito via declare options:

polifonia.dspfaust
declare options "[nvoices:8]";
import("stdfaust.lib");

// process abaixo será replicado 8 vezes pelo compilador,
// um por nota simultânea — o usuário pode tocar 8 notas juntas.

freq = hslider("freq", 440, 50, 2000, 0.01);
gain = hslider("gain", 0.5, 0, 1, 0.01);
gate = button("gate");

process = os.osc(freq) * gain * gate <: _ , _;

Compilando isso pra VST com faust2vst -nvoices 8 (módulo 08), o plugin aparece como instrument no DAW, recebe MIDI direto, e toca polifônico.

§ 03

Sintetizador mono — uma voz.

Antes de polifônico, fazemos monofônico. Um detalhe importante: gate é binário. Multiplicar por 0 quando solta corta abruptamente — vira "click" feio. Solução: envelope.

synth_mono.dspfaust
declare name "Mono Synth";
import("stdfaust.lib");

freq = hslider("freq", 440, 50, 2000, 0.01);
gain = hslider("gain", 0.5, 0, 1, 0.01);
gate = button("gate");

// Envelope ADSR (attack, decay, sustain, release) suaviza o gate
env = en.adsr(0.01, 0.1, 0.7, 0.3, gate);

// Sintetizador básico: oscilador * envelope * velocity
process = os.sawtooth(freq) * env * gain <: _ , _;

Sem o envelope, soltar a tecla cortaria o som no meio do ciclo. Com ele, suaviza pra zero em 300 ms (o release do ADSR).

§ 04

Polifonia automática.

Adicionando declare options "[nvoices:8]" ao código acima, o compilador FAUST replica internamente o process 8 vezes. Cada nota tocada vai pra uma voz livre.

synth_poly.dspfaust
declare name "Poly Synth";
declare options "[nvoices:8]";
import("stdfaust.lib");

freq = hslider("freq", 440, 50, 2000, 0.01);
gain = hslider("gain", 0.5, 0, 1, 0.01);
gate = button("gate");

env = en.adsr(0.01, 0.1, 0.7, 0.3, gate);

process = os.sawtooth(freq) * env * gain <: _ , _;
Como o wrapper gerencia vozes

Quando você toca uma nota nova: o wrapper procura uma voz livre (com gate=0 e envelope finalizado). Se não tem, ele "rouba" a voz mais antiga (voice stealing). Quando você solta: gate vai pra 0, envelope decai pelo release, voz fica livre de novo.

§ 05

Envelope ADSR.

en.adsr(a, d, s, r, gate) — Attack, Decay, Sustain, Release. Tempos em segundos, sustain entre 0 e 1.

EstágioO que fazPra som de
AttackSobe de 0 ao picoórgão: instantâneo; pad: 1-2s
DecayCai do pico ao sustainpiano: rápido; pad: médio
SustainMantém enquanto seguraórgão: 1.0; piano: 0.3
ReleaseCai a 0 ao soltarórgão: 0.1s; pad: 2s

Presets clássicos:

InstrumentoADSR
Pluck/piano0.0010.50.00.3
Órgão0.0050.01.00.05
Pad1.50.50.72.0
Bass0.0050.20.50.1

Outras opções: en.are(attack, release) (só attack/release), en.adsre(a, d, s, r, decay) (versão exponencial).

§ 06

Aplicação: synth polifônico completo.

Sintetizador playável com oscilador, ADSR ajustável, filtro com envelope, e UI organizada em tabs.

synth_full.dspfaust
declare name        "Poly Synth pra Igreja";
declare author      "Jefferson Cunha";
declare options     "[nvoices:12]";
declare category    "Synthesizer";
import("stdfaust.lib");

// === MIDI bindings (labels exatos) ===
freq = hslider("freq", 440, 50, 2000, 0.01);
gain = hslider("gain", 0.5, 0, 1, 0.01);
gate = button("gate");

// === OSC ===
wave = nentry("t:Osc/forma [style:menu{'sawtooth':0;'square':1;'tri':2;'sine':3}]", 0, 0, 3, 1);
detune = hslider("t:Osc/detune [unit:cents]", 0, -50, 50, 0.1);

// Aplica detune (cents → ratio: 2^(cents/1200))
detuned_freq = freq * pow(2, detune / 1200);

oscs = os.sawtooth(detuned_freq) , os.square(detuned_freq)
     , os.triangle(detuned_freq) , os.osc(detuned_freq);
osc_out = oscs : ba.selectn(4, wave);

// === ADSR de amplitude ===
atk = hslider("t:Env/attack [unit:s]", 0.01, 0.001, 3, 0.001);
dec = hslider("t:Env/decay [unit:s]", 0.1, 0.001, 3, 0.001);
sus = hslider("t:Env/sustain", 0.7, 0, 1, 0.01);
rel = hslider("t:Env/release [unit:s]", 0.3, 0.001, 5, 0.001);
amp_env = en.adsr(atk, dec, sus, rel, gate);

// === Filter low pass com envelope ===
cutoff = hslider("t:Filter/cutoff [unit:Hz][scale:log]", 2000, 100, 20000, 1);
env_amount = hslider("t:Filter/env amount", 0.3, 0, 1, 0.01);
modulated_cutoff = cutoff * (1 + env_amount * amp_env * 4);
filtered = osc_out : fi.lowpass(2, modulated_cutoff);

// === Master ===
master = hslider("master [unit:dB]", -6, -60, 0, 0.1) : ba.db2linear;

process = filtered * amp_env * gain * master <: _ , _;

Esse é um sintetizador de verdade. 12 vozes, 4 formas de onda, ADSR completo, filtro com envelope, detune fino. UI organizada em 3 tabs (Osc, Env, Filter).

Compilou. Toca?

No Faust IDE: clica em Run → vai aparecer um "MIDI in" pra você plugar teu teclado. No DAW (depois do módulo 08): plugin aparece como Instrument, você cria uma track de MIDI e arrasta o plugin nela. Toca o teclado e ouve.

Glossário rápido
declare options "[nvoices:N]"
Define polifonia de N vozes.
"freq" (label)
Slider que recebe nota MIDI convertida pra Hz.
"gain" (label)
Slider que recebe velocity (0 a 1).
"gate" (button)
Button que recebe note on/off.
en.adsr(a, d, s, r, gate)
Envelope ADSR.
en.are(a, r, gate)
Envelope AR simplificado.
voice stealing
Quando todas vozes estão em uso, o wrapper "rouba" a voz mais antiga.
cents
Unidade de afinação. 100 cents = 1 semitom. Detune em cents.
declare category "Synthesizer"
Categoriza como instrumento no DAW.
pow(2, c/1200)
Converte cents pra ratio multiplicativa de frequência.
