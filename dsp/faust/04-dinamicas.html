Dinâmicas: gate e compressor.

§ 01

Anatomia de um compressor.

Compressor "amassa" o que está alto e mantém o que está baixo. Reduz a dinâmica.

5 controles que aparecem em todo compressor do mundo:

ControleO que fazUnidade
Thresholdnível em que o compressor "liga"dB (geralmente -20 a -10)
Ratioquanto comprime acima do thresholdX:1 (2:1 leve, 10:1 limit)
Attacktempo pra começar a comprimirms (1 ms a 100 ms)
Releasetempo pra soltar depois do picoms (50 ms a 1000 ms)
Makeup Gainganho pra compensar o que foi comprimidodB (0 a +12)

Ratio 4:1 com threshold -20 dB: pico de -10 dB entra, sai como (-20 + (10/4)) = -17.5 dB. O excesso de 10 dB virou 2.5 dB. Comprimiu 7.5 dB.

§ 02

co.compressor_mono — o pronto.

FAUST traz um compressor pronto: co.compressor_mono(ratio, threshold, attack, release). Não precisa implementar nada — é uma linha.

comp_simples.dspfaust
declare name "Compressor Simples";
import("stdfaust.lib");

ratio    = hslider("ratio", 4, 1, 20, 0.1);
thresh   = hslider("threshold [unit:dB]", -18, -60, 0, 0.1);
attack   = hslider("attack [unit:ms]", 10, 0.1, 100, 0.1) : *(0.001);
release  = hslider("release [unit:ms]", 100, 10, 1000, 1)  : *(0.001);
makeup_db = hslider("makeup [unit:dB]", 0, 0, 24, 0.1);

makeup = makeup_db : ba.db2linear;

process = co.compressor_mono(ratio, thresh, attack, release) * makeup;

Detalhes:

  • FAUST espera attack/release em segundos, então o slider em ms é multiplicado por 0.001.
  • Makeup gain é aplicado depois — multiplicação simples.
  • Em stereo: aplica co.compressor_mono em paralelo nos dois canais (ou usa co.compressor_stereo que linka os 2).
§ 03

Gain reduction meter.

Operador profissional quer ver quanto o compressor está reduzindo. hbargraph mostra isso visualmente no DAW.

comp_meter.dspfaust
declare name "Compressor com meter";
import("stdfaust.lib");

ratio    = hslider("ratio", 4, 1, 20, 0.1);
thresh   = hslider("threshold [unit:dB]", -18, -60, 0, 0.1);
attack   = hslider("attack [unit:ms]", 10, 0.1, 100, 0.1) * 0.001;
release  = hslider("release [unit:ms]", 100, 10, 1000, 1) * 0.001;

// ganho de redução (linear: 1.0 = sem redução, < 1.0 = atenua)
gr = co.compression_gain_mono(ratio, thresh, attack, release);

// meter: passa o ganho adiante e mostra em dB no bargraph (side-effect)
meter(g) = attach(g, g : ba.linear2db : hbargraph("redução [unit:dB]", -24, 0));

process(x) = x * (x : gr : meter);

attach(a, b) é o segredo: passa a adiante como saída e usa b só como side-effect (o meter "lê" o valor mas não muda o áudio).

§ 04

Compressor manual (envelope + gain).

Pra entender o que co.compressor_mono faz por dentro, vamos construir um do zero. 2 partes: detecção de envelope (quão alto está o sinal agora) e aplicação de ganho (quanto reduzir).

comp_manual.dspfaust
import("stdfaust.lib");

ratio = hslider("ratio", 4, 1, 20, 0.1);
thresh_db = hslider("threshold [unit:dB]", -18, -60, 0, 0.1);
attack = hslider("attack [unit:ms]", 10, 0.1, 100, 0.1) : *(0.001);
release = hslider("release [unit:ms]", 100, 10, 1000, 1) : *(0.001);

// 1. Detecta envelope (RMS-like via amp_follower)
envelope(x) = x : en.amp_follower(release) : ba.linear2db;

// 2. Calcula a redução em dB pra cada amostra
gain_reduction(env) = ba.if(env > thresh_db,
                          (env - thresh_db) * (1/ratio - 1),
                          0);

// 3. Aplica a redução em ganho linear
process(x) = x * (envelope(x) : gain_reduction : ba.db2linear);

Lê-se: "pega x, calcula o envelope em dB, se passou do threshold subtrai o excesso vezes (1/ratio − 1), volta pra linear, multiplica x por isso".

Por que (1/ratio − 1)

Se ratio = 4 e o sinal está 8 dB acima do threshold, a saída deve estar 8/4 = 2 dB acima. Então a redução é 8 − 2 = 6 dB. Generalizando: redução = excesso × (1 − 1/ratio). Como queremos atenuar (ganho negativo), multiplicamos por (1/ratio − 1) que é negativo.

§ 05

Gate — silenciar o que está baixo.

Gate é o oposto do compressor: cala o que está abaixo de um threshold. Útil pra eliminar ruído de fundo quando o mic está parado.

gate.dspfaust
import("stdfaust.lib");

thresh_db = hslider("gate threshold [unit:dB]", -45, -90, 0, 0.1);
hold_ms   = hslider("hold [unit:ms]", 50, 0, 500, 1) : *(0.001);
release   = hslider("release [unit:ms]", 100, 10, 2000, 1) : *(0.001);

// co.gate_mono(threshold_db, attack_sec, hold_sec, release_sec, x)
process = co.gate_mono(thresh_db, 0.001, hold_ms, release);

Threshold típico pra voz de mic dinâmico: -45 a -55 dB. Hold curto (50 ms) pra não cortar palavras com gap natural. Release moderado (100-300 ms) pra não ouvir o gate fechando.

§ 06

Aplicação: compressor de pregador.

Plugin completo: gate + compressor + makeup, pronto pra usar no canal do pulpit microphone.

pregador.dspfaust
declare name "Compressor de Pregador";
declare author "Jefferson Cunha";
declare description "Gate + compressor calibrado pra mic de voz em culto";
import("stdfaust.lib");

// ===== GATE =====
gate_thresh = hslider("gate/threshold [unit:dB]", -50, -90, 0, 0.1);
gate_hold   = hslider("gate/hold [unit:ms]", 100, 0, 500, 1) : *(0.001);
gate_rel    = hslider("gate/release [unit:ms]", 200, 10, 2000, 1) : *(0.001);

// ===== COMPRESSOR =====
comp_ratio  = hslider("comp/ratio", 3, 1, 20, 0.1);
comp_thresh = hslider("comp/threshold [unit:dB]", -18, -60, 0, 0.1);
comp_atk    = hslider("comp/attack [unit:ms]", 5, 0.1, 100, 0.1) : *(0.001);
comp_rel    = hslider("comp/release [unit:ms]", 80, 10, 1000, 1) : *(0.001);

// ===== MAKEUP =====
makeup = hslider("makeup [unit:dB]", 6, 0, 24, 0.1) : ba.db2linear;

// ===== METER =====
gr = co.compression_gain_mono(comp_ratio, comp_thresh, comp_atk, comp_rel)
   : ba.linear2db : hbargraph("redução [unit:dB]", -24, 0);

// ===== CHAIN =====
chain = co.gate_mono(gate_thresh, 0.001, gate_hold, gate_rel)
      : co.compressor_mono(comp_ratio, comp_thresh, comp_atk, comp_rel)
      : *(makeup);

process = chain <: _ , _;

Os valores default (ratio 3, threshold -18, attack 5 ms, release 80 ms, makeup 6 dB) são um preset razoável pra voz falada. Funciona out-of-the-box pra pregador em mic dinâmico tipo SM58.

Por que esses defaults

Ratio 3:1 — compressão "musical", não é limit. Threshold -18 dB — começa a agir só nos picos. Attack 5 ms — pega o pico mas deixa o "transiente" passar (não fica chato). Release 80 ms — solta rápido pra naturalidade, mas não tão rápido a ponto de "respirar" o ruído de fundo. Makeup +6 dB — compensa a redução típica.

Glossário rápido
co.compressor_mono(R, T, A, R)
Compressor pronto. Ratio, threshold dB, attack/release em segundos.
co.compressor_stereo
Versão stereo linkada (detecção comum).
co.gate_mono(T, A, H, R)
Gate. Threshold dB, attack, hold, release em segundos.
co.compression_gain_mono
Devolve só o ganho de redução (pra meter ou sidechain).
en.amp_follower(rel)
Envelope follower simples — extrai o "contorno" do sinal.
ba.if(cond, a, b)
Condicional. Se cond então a senão b.
ba.db2linear
Converte dB → ganho linear (10^(x/20)).
ba.linear2db
Converte ganho linear → dB.
attach(a, b)
Anexa b ao caminho de a sem afetar o áudio (pra meters).
hbargraph("L", min, max)
Level meter horizontal. Vira indicador visual no DAW.
