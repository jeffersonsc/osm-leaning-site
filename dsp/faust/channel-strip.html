Projeto — Channel Strip

Meu primeiro channel strip.

Plugin de produção real juntando tudo dos módulos 01–06 num único arquivo: input gain, HPF/LPF com bypass, gate, compressor, EQ paramétrico de 4 bandas, sends de delay e reverb, e MASTER fader vertical com meter. § 01

Topologia do sinal.

O channel strip é a cadeia mais comum de uma mesa de som: cada estágio molda o sinal antes do próximo. Aqui está a ordem clássica — a mesma que você encontra num X32, Wing, Behringer Wing, etc.

fluxo de sinalascii
IN → gain → [meter] → HPF → LPF → GATE → COMP → EQ₁ → EQ₂ → EQ₃ → EQ₄ → DELAY → REVERB → gain → [meter] → OUT
                                  ↓       ↓
                              [GR meter] [GR meter]

Cada estágio é uma função FAUST independente. O sinal flui por : (composição série). Os meters são branches paralelos via attach, lendo o sinal sem consumi-lo.

O que cada estágio faz

  • Input gain — trim de entrada em dB pra normalizar o nível antes de processar.
  • HPF (passa-alta, 80 Hz) — corta rumble de palco, vento no mic, vibração do pedestal.
  • LPF (passa-baixa, 12 kHz) — corta hiss, agudos abrasivos, harmônicos de PA.
  • Gate — silencia o canal quando o sinal cai abaixo do threshold (vazamento de outros mics, ruído de fundo).
  • Compressor — reduz a diferença entre pico e nível médio (voz fica consistente sem clip).
  • EQ 4 bandas paramétrico — esculpe o timbre (cada banda tem freq, gain e Q ajustáveis).
  • Delay send — cópia do sinal repetida no tempo com feedback (eco controlado).
  • Reverb send — cauda de ambiente (sala, hall, igreja).
  • Output gain — ajuste final pra mandar pro mix bus.
§ 02

Plugin completo.

Copia o bloco inteiro, cola no editor.faust.grame.fr, clica em Run. O plugin aparece com 7 tabs (Input, Filters, Gate, Comp, EQ, FX, Output) e roda direto.

Layout de mesa digital — escolhas visuais
  • Knobs em vez de sliders — [style:knob] em todo controle, parece mesa de verdade.
  • EQ em colunas — cada banda (Low/LowMid/HighMid/High) num v: group dentro de um h:bandas, gain/freq/Q empilhados, 4 colunas lado-a-lado.
  • FX em colunas — Delay e Reverb também em v: groups lado-a-lado dentro de h:sends.
  • Filters em colunas — HPF e LPF cada um numa coluna com checkbox + freq.
  • MASTER vertical — saída usa vslider (fader vertical) ao invés de knob, parece o fader master de uma mesa.
  • Meters I/O verticais — vbargraph no input e output (canal de mesa), hbargraph nos GR meters (barra de redução).
Sobre o gate

A função co.gate_gain_mono que muitos exemplos online usam não existe na stdfaust.lib — dá erro undefined symbol : gate_gain_mono. Aqui o gate foi implementado manual: envelope follower (an.amp_follower_ar) + comparação com threshold + smoothing pra evitar zipper.

channel_strip.dspfaust
declare name      "Channel Strip";
declare author    "Jefferson Cunha";
declare version   "1.0";
declare category  "Channel Strip";
import("stdfaust.lib");

//================== INPUT ==================
in_gain     = hslider("t:Input/[0]gain [unit:dB][style:knob]", 0, -24, 24, 0.1) : ba.db2linear;
in_meter(s) = attach(s, s : abs : ba.linear2db : vbargraph("t:Input/[1]in [unit:dB]", -60, 0));

//================== FILTERS (HPF / LPF lado-a-lado) ==================
hpf_on   = checkbox("t:Filters/h:secao/v:HPF/[0]on");
hpf_freq = hslider("t:Filters/h:secao/v:HPF/[1]freq [unit:Hz][scale:log][style:knob]", 80,    20,   500,   1);
lpf_on   = checkbox("t:Filters/h:secao/v:LPF/[0]on");
lpf_freq = hslider("t:Filters/h:secao/v:LPF/[1]freq [unit:Hz][scale:log][style:knob]", 12000, 1000, 20000, 1);

hpf = ba.bypass1(1 - hpf_on, fi.highpass(2, hpf_freq));
lpf = ba.bypass1(1 - lpf_on, fi.lowpass(2, lpf_freq));

//================== GATE (knobs em linha + GR meter) ==================
g_thresh  = hslider("t:Gate/h:controles/[0]threshold [unit:dB][style:knob]", -40, -80, 0,    0.1);
g_attack  = hslider("t:Gate/h:controles/[1]attack [unit:ms][style:knob]",    1,   0.1, 50,   0.1) * 0.001;
g_release = hslider("t:Gate/h:controles/[2]release [unit:ms][style:knob]",   100, 10,  1000, 1)   * 0.001;

// Envelope follower com attack/release (peak detector suavizado)
g_env(x) = abs(x) : an.amp_follower_ar(g_attack, g_release);

// Gate gain: 1 quando env > threshold, 0 abaixo; 5ms de smoothing pra evitar clique
g_gain(x) = (g_env(x) > ba.db2linear(g_thresh)) : si.smooth(ba.tau2pole(0.005));

g_meter(g)    = attach(g, g : ba.linear2db : hbargraph("t:Gate/[3]GR [unit:dB]", -60, 0));
gate_stage(x) = x * (x : g_gain : g_meter);

//================== COMPRESSOR (knobs em linha + GR meter) ==================
c_thresh  = hslider("t:Comp/h:controles/[0]threshold [unit:dB][style:knob]", -18, -60, 0,    0.1);
c_ratio   = hslider("t:Comp/h:controles/[1]ratio[style:knob]",                4,   1,   20,   0.1);
c_attack  = hslider("t:Comp/h:controles/[2]attack [unit:ms][style:knob]",     10,  0.1, 100,  0.1) * 0.001;
c_release = hslider("t:Comp/h:controles/[3]release [unit:ms][style:knob]",    100, 10,  1000, 1)   * 0.001;
c_makeup  = hslider("t:Comp/h:controles/[4]makeup [unit:dB][style:knob]",     0,   0,   24,   0.1) : ba.db2linear;

c_gain        = co.compression_gain_mono(c_ratio, c_thresh, c_attack, c_release);
c_meter(g)    = attach(g, g : ba.linear2db : hbargraph("t:Comp/[5]GR [unit:dB]", -24, 0));
comp_stage(x) = x * (x : c_gain : c_meter) * c_makeup;

//================== EQ 4 BANDAS — vgroup por banda dentro de hgroup ==================
// Cada banda fica numa coluna (vgroup) com gain/freq/Q empilhados em knobs.
// As 4 colunas ficam lado-a-lado (hgroup "bandas") tipo channel strip de mesa.
b1_gain = hslider("t:EQ/h:bandas/v:Low/[0]gain [unit:dB][style:knob]",             0,    -18, 18,    0.1);
b1_freq = hslider("t:EQ/h:bandas/v:Low/[1]freq [unit:Hz][scale:log][style:knob]",  120,  20,  500,   1);
b1_q    = hslider("t:EQ/h:bandas/v:Low/[2]Q[style:knob]",                          1.0,  0.1, 10,    0.01);

b2_gain = hslider("t:EQ/h:bandas/v:LowMid/[0]gain [unit:dB][style:knob]",             0,    -18, 18,    0.1);
b2_freq = hslider("t:EQ/h:bandas/v:LowMid/[1]freq [unit:Hz][scale:log][style:knob]",  500,  100, 2000,  1);
b2_q    = hslider("t:EQ/h:bandas/v:LowMid/[2]Q[style:knob]",                          1.0,  0.1, 10,    0.01);

b3_gain = hslider("t:EQ/h:bandas/v:HighMid/[0]gain [unit:dB][style:knob]",             0,    -18, 18,    0.1);
b3_freq = hslider("t:EQ/h:bandas/v:HighMid/[1]freq [unit:Hz][scale:log][style:knob]",  2500, 500, 8000,  1);
b3_q    = hslider("t:EQ/h:bandas/v:HighMid/[2]Q[style:knob]",                          1.0,  0.1, 10,    0.01);

b4_gain = hslider("t:EQ/h:bandas/v:High/[0]gain [unit:dB][style:knob]",             0,    -18,  18,    0.1);
b4_freq = hslider("t:EQ/h:bandas/v:High/[1]freq [unit:Hz][scale:log][style:knob]",  8000, 2000, 20000, 1);
b4_q    = hslider("t:EQ/h:bandas/v:High/[2]Q[style:knob]",                          1.0,  0.1,  10,    0.01);

eq = fi.peak_eq(b1_gain, b1_freq, b1_q)
   : fi.peak_eq(b2_gain, b2_freq, b2_q)
   : fi.peak_eq(b3_gain, b3_freq, b3_q)
   : fi.peak_eq(b4_gain, b4_freq, b4_q);

//================== FX SENDS — Delay + Reverb lado-a-lado ==================
d_time = hslider("t:FX/h:sends/v:Delay/[0]time [unit:ms][style:knob]",    250, 1, 2000, 1) * 0.001;
d_fb   = hslider("t:FX/h:sends/v:Delay/[1]feedback [unit:%][style:knob]", 30,  0, 90,   1) * 0.01;
d_mix  = hslider("t:FX/h:sends/v:Delay/[2]mix [unit:%][style:knob]",      0,   0, 100,  1) * 0.01;

delay_fx      = +~(de.fdelay(192000, d_time * ma.SR) : *(d_fb));
delay_send(x) = x * (1 - d_mix) + delay_fx(x) * d_mix;

r_size = hslider("t:FX/h:sends/v:Reverb/[0]size [unit:%][style:knob]", 70, 0, 100, 1) * 0.01;
r_damp = hslider("t:FX/h:sends/v:Reverb/[1]damp [unit:%][style:knob]", 30, 0, 100, 1) * 0.01;
r_mix  = hslider("t:FX/h:sends/v:Reverb/[2]mix [unit:%][style:knob]",  0,  0, 100, 1) * 0.01;

// mono_freeverb(fb1, fb2, damp, spread) — fb1=room, fb2=diffusão
reverb_fx(x)   = x : re.mono_freeverb(r_size, r_size, r_damp, 0);
reverb_send(x) = x * (1 - r_mix) + reverb_fx(x) * r_mix;

//================== OUTPUT — MASTER fader vertical + meter vertical ==================
out_gain     = vslider("t:Output/[0]MASTER [unit:dB]", 0, -24, 24, 0.1) : ba.db2linear;
out_meter(s) = attach(s, s : abs : ba.linear2db : vbargraph("t:Output/[1]out [unit:dB]", -60, 0));

//================== SIGNAL FLOW ==================
process(x) = in_meter(x * in_gain)
            : hpf : lpf
            : gate_stage
            : comp_stage
            : eq
            : delay_send
            : reverb_send
            : *(out_gain)
            : out_meter;
§ 03

Truques de UI DAW-ready.

Os detalhes que separam um plugin de aula de um plugin que dá pra usar de verdade:

Ordem, unidade, bypass, segurança
  • Prefixo numérico [0], [1], [2]... no label força a ordem dos controles dentro de cada tab. Sem ele, o DAW exibe em ordem alfabética e o release vem antes do attack.
  • Todos os tempos em ms × 0.001 no slider e o cálculo interno em segundos. O DAW mostra "10 ms" enquanto o DSP recebe 0.01. Mais legível pro operador.
  • Makeup em dB → linear via : ba.db2linear no fim da chain do slider. Slider mostra dB, DSP multiplica por linear.
  • Bypass real com ba.bypass1 — quando checkbox=off, o filtro é literalmente removido da cadeia (zero CPU), não só "freq alta demais".
  • Feedback < 90 % no delay pra evitar explodir no sustain. Pro auto-oscilação criativa, deixe 95.

Grupos aninhados pra layout de mesa

O segredo do visual de channel strip é aninhar prefixos de grupo no label. Cada / abre um nível, e os prefixos h:, v: e t: controlam a direção.

anatomia do label de EQfaust
"t:EQ/h:bandas/v:Low/[0]gain [unit:dB][style:knob]"
//  └─┬─┘ └──┬───┘ └─┬─┘ └────────────┬─────────────┘
//    │      │       │                │
//    │      │       │                └─ controle: gain em dB, com knob
//    │      │       └─ vgroup "Low": gain/freq/Q empilhados verticalmente
//    │      └─ hgroup "bandas": 4 bandas lado-a-lado (Low | LowMid | HighMid | High)
//    └─ tgroup "EQ": tab no topo do plugin

O mesmo padrão se repete em Filters (HPF/LPF lado-a-lado), FX (Delay/Reverb lado-a-lado), Gate e Comp (knobs em linha + GR meter embaixo). Esse aninhamento é o que dá ao plugin a "cara" de uma channel strip de X32/Wing, mesmo dentro do editor padrão do FAUST.

Por que o gate foi feito manual

Várias referências online (incluindo respostas de IA) mencionam co.gate_gain_mono(thresh, att, hold, rel) como função padrão. Ela não existe na compressors.lib atual — só co.gate_mono (que retorna o áudio já gateado, sem o ganho separado).

Pra ter um GR meter a gente precisa do ganho separado, então a gente constrói:

gate manualfaust
// 1. Envelope do sinal (rastreador de pico)
g_env(x) = abs(x) : an.amp_follower_ar(g_attack, g_release);

// 2. Boolean: env acima do threshold? (0 ou 1)
// 3. Smoothing de 5ms pra evitar clique no transient
g_gain(x) = (g_env(x) > ba.db2linear(g_thresh)) : si.smooth(ba.tau2pole(0.005));

an.amp_follower_ar(att, rel, x) é o envelope follower padrão do FAUST, com tempos de attack e release separados. A comparação > threshold gera 0 ou 1. O si.smooth com 5ms remove o clique na transição.

§ 04

Onde ir a partir daqui.

Esse plugin já é completo o suficiente pra usar num culto. Próximos passos naturais:

  • Versão estéreo — duplicar a chain pra L/R e linkar os meters (módulo 07 traz process de N canais).
  • De-esser — adicionar um sidechain no compressor com filtro passa-banda na região de 5–8 kHz pra mic de pregador.
  • Saturação tape — estágio de soft-clipping com tanh entre EQ e FX pra colorir.
  • Sidechain — comprimir música via sinal do microfone (ducking quando o pregador fala).
  • Preset bank — salvar valores típicos (voz pregador, voz cantor, instrumento) e exportar como VST3 com faust2vst3 (módulo 08).
  • Hold no gate — adicionar um terceiro tempo entre attack e release que segura o gate aberto por X ms depois que o sinal cai abaixo do threshold.
Pronto pro DAW

Depois de testar no editor.faust.grame.fr, o próximo passo é exportar como VST3/AU/LV2 com faust2vst3 channel_strip.dsp (módulo 08). Aí o plugin aparece direto no Reaper/Logic/Ardour pra usar nos canais de qualquer projeto.
