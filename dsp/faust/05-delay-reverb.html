§ 01

de.delay — atraso simples.

Delay é o bloco mais básico de processamento temporal. Tudo o que envolve "ouvir o passado" — eco, reverb, chorus, flanger — começa com delay.

FAUST tem 3 níveis de delay:

FunçãoCaracterística
mem1 amostra de atraso (1/48000 s em 48 kHz)
@(N)N amostras de atraso (fixo na compilação)
de.delay(maxN, n)Delay com max N amostras, atual n (variável)
de.fdelay(maxN, n)Fractional delay (n não-inteiro, interpolado)
delay_simples.dspfaust
import("stdfaust.lib");

// Delay de 250 ms (atraso fixo em ms convertido pra samples)
delay_ms = hslider("delay [unit:ms]", 250, 10, 2000, 1);
delay_samples = delay_ms * ma.SR / 1000;

// max 96000 samples = 2 segundos em 48 kHz
process = _ : de.delay(96000, delay_samples);

ma.SR é a sample rate atual. delay_ms * SR / 1000 converte milissegundos pra amostras.

§ 02

Feedback e o dub delay.

Delay simples só faz um eco. Pra ter múltiplos ecos decrescentes (estilo dub, eco de pedra), você precisa de feedback: a saída do delay volta pra entrada com atenuação.

O operador ~ (recursivo) é o segredo do feedback em FAUST.

dub_delay.dspfaust
declare name "Dub Delay";
import("stdfaust.lib");

delay_ms = hslider("delay [unit:ms]", 375, 10, 2000, 1);
delay_samples = delay_ms * ma.SR / 1000;

feedback = hslider("feedback", 0.6, 0, 0.95, 0.01);
mix      = hslider("mix", 0.3, 0, 1, 0.01);

// O dub clássico: feedback passa por lowpass pra "embaçar" cada repetição
delay_line = de.delay(96000, delay_samples) : fi.lowpass(2, 2500);

// ~ é o feedback: a saída de delay_line volta multiplicada por feedback
delayed(x) = x : (+ : delay_line) ~ *(feedback);

// dry/wet mix
process(x) = x * (1 - mix) + delayed(x) * mix;
O operador ~

f ~ g significa: o output de f entra em g, e a saída de g volta pra entrada de f. É a forma básica de criar loops de feedback. Cuidado: feedback > 1 explode (overflow). Sempre limite o slider pra ≤ 0.95.

§ 03

Sincronia com BPM.

Pra louvor com banda, delay precisa estar sincronizado com o BPM (semínima, colcheia, etc.). FAUST não recebe BPM do DAW direto — você precisa adicionar como slider, ou (no plugin VST) configurar pra receber tempo.

delay_sync.dspfaust
import("stdfaust.lib");

bpm = hslider("BPM", 120, 60, 200, 1);

// Divisão rítmica: 0=semibreve, 1=mínima, 2=semínima, 3=colcheia, 4=semicolcheia
div = nentry("divisão [style:menu{'1/1':1;'1/2':2;'1/4':4;'1/8':8;'1/16':16}]", 4, 1, 16, 1);

// segundos por semínima = 60/BPM; semínima/div = duração da divisão
delay_ms = (60 / bpm * 4 / div) * 1000;
delay_samples = delay_ms * ma.SR / 1000;

feedback = hslider("feedback", 0.5, 0, 0.9, 0.01);
mix = hslider("mix", 0.25, 0, 1, 0.01);

delay_line = de.fdelay(96000, delay_samples);
wet(x) = x : (+ : delay_line) ~ *(feedback);

process(x) = x * (1 - mix) + wet(x) * mix;
§ 04

re.mono_freeverb — reverb em 1 linha.

Reverb (reverberação) simula o "ambiente" — um som tocando numa sala grande versus banheiro. FAUST traz vários algoritmos prontos.

freeverb.dspfaust
declare name "Freeverb Simples";
import("stdfaust.lib");

size  = hslider("tamanho da sala", 0.5, 0, 1, 0.01);
damp  = hslider("damping", 0.5, 0, 1, 0.01);
spread = hslider("spread", 0.5, 0, 1, 0.01);
mix    = hslider("mix", 0.3, 0, 1, 0.01);

wet(x) = x : re.mono_freeverb(damp, 0.5, size, spread);

process(x) = x * (1 - mix) + wet(x) * mix;

Outros reverbs:

  • re.stereo_freeverb — versão stereo do Freeverb.
  • re.fdnrev0 — Feedback Delay Network reverb (mais natural).
  • re.zita_rev1 — Zita Rev1, baseado no Plate Reverb clássico de Fons Adriaensen.
  • re.dattorro_rev — Dattorro reverb (figura-8 estrutural, smooth).
§ 05

Schroeder reverb por dentro.

Pra entender como reverb funciona, a estrutura clássica do Schroeder reverb: vários comb filters em paralelo + vários all-pass em série.

  • Comb filter = delay + feedback. Cria "ressonâncias" no espectro.
  • All-pass = filtro que muda fase sem mudar amplitude. "Difunde" as ressonâncias dos combs.
  • 4 combs em paralelo + 2 all-pass em série = reverb tipo "câmara" simples.
schroeder.dspfaust
import("stdfaust.lib");

// Cada comb com delay primo (evita ressonâncias coincidentes)
comb1 = fi.fb_comb(4096, 1601, 1, 0.842);
comb2 = fi.fb_comb(4096, 1867, 1, 0.812);
comb3 = fi.fb_comb(4096, 2053, 1, 0.783);
comb4 = fi.fb_comb(4096, 2251, 1, 0.768);

ap1 = fi.allpass_comb(2048, 347, -0.7);
ap2 = fi.allpass_comb(2048, 113, -0.7);

// Pipeline: split em 4 combs, soma, passa por 2 all-pass
schroeder(x) = x <: comb1, comb2, comb3, comb4 :> _ : ap1 : ap2;

mix = hslider("mix", 0.2, 0, 1, 0.01);
process(x) = x * (1 - mix) + schroeder(x) * mix;

É um reverb simples e instrutivo, mas re.mono_freeverb e re.zita_rev1 soam muito melhor — eles usam variações modernas dessa mesma ideia.

§ 06

Aplicação: reverb sutil de pregador.

Em igreja, reverb na voz é polêmico. Pouco demais e a voz fica "seca, sem peso". Demais e fica fantasma incompreensível. O equilíbrio: pré-delay curto + reverb curto + mix baixo + EQ no wet pra tirar grave.

reverb_pregador.dspfaust
declare name "Reverb de Pregador";
declare author "Jefferson Cunha";
import("stdfaust.lib");

// === pré-delay (separa wet do dry pra clareza) ===
pre_ms = hslider("pre-delay [unit:ms]", 20, 0, 100, 1);
pre_samples = pre_ms * ma.SR / 1000;

// === reverb (Zita: soa mais natural pra voz) ===
rev_time = hslider("reverb time [unit:s]", 1.2, 0.5, 3, 0.1);

// === EQ no wet — corta grave e brilho exagerado ===
wet_hp = hslider("wet/low cut [unit:Hz]", 200, 50, 800, 1);
wet_lp = hslider("wet/high cut [unit:Hz]", 6000, 2000, 15000, 100);

// === mix ===
mix = hslider("mix", 0.15, 0, 0.5, 0.01);

// pipeline do wet
wet(x) = x : de.delay(9600, pre_samples)
           : re.mono_freeverb(0.5, 0.5, rev_time * 0.3, 0.6)
           : fi.highpass(2, wet_hp)
           : fi.lowpass(2, wet_lp);

process(x) = (x * (1 - mix) + wet(x) * mix) <: _ , _;
Defaults pra pregador

Pre-delay 20 ms, reverb time 1.2 s, EQ do wet cortando abaixo de 200 Hz e acima de 6 kHz, mix 15%. Esse preset dá "presença e leve ar" sem deixar fantasma. Pra louvor, sobe mix pra 25-30% e aumenta reverb time pra 1.8 s.

Glossário rápido
mem
Delay de 1 amostra.
@(N)
Atraso fixo de N amostras.
de.delay(max, n)
Delay variável até max amostras, atraso atual n.
de.fdelay(max, n)
Delay fracionário (interpola entre amostras).
~
Operador de feedback recursivo.
ma.SR
Sample rate atual (geralmente 48000).
re.mono_freeverb
Freeverb mono. (damping, sidefreq, roomsize, spread).
re.stereo_freeverb
Versão stereo.
re.zita_rev1
Zita Rev1 — soa mais natural pra voz.
fi.fb_comb(max, dly, b0, fb)
Comb com feedback — bloco básico de reverb.
fi.allpass_comb(max, dly, fb)
All-pass comb — difunde sem colorir.
