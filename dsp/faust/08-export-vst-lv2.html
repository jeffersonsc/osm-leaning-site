§ 01

Duas rotas: web export ou local.

FAUST tem duas formas de gerar o binário do plugin: pelo serviço web do Faust IDE, ou rodando o compilador localmente. Pra quem só quer testar 1 plugin, o web export resolve em 30 segundos.

RotaQuando usarLimitação
Web export1 plugin, testar rápido, sem instalar nadadepende do servidor, pode ficar fora do ar
Localvários plugins, automação, controle totalprecisa instalar FAUST + dependências

Web export — pra começar agora

  1. No faustide.grame.fr, abre seu plugin.
  2. Botão Export (📦) no canto superior direito.
  3. Escolhe a plataforma: linux, osx, windows, web.
  4. Escolhe a arquitetura: vst3, lv2, au, standalone, jaqt.
  5. Clica em Compile. Baixa o ZIP com o plugin.

É realmente assim de simples. Pra um plugin de teste, esse é o caminho mais rápido.

§ 02

Instalar FAUST local.

Pra uso sério (vários plugins, scripts), instala localmente.

Linux (Ubuntu/Debian)

bashlinux
sudo apt install faust faust-tools

# verifica
faust --version

macOS (via Homebrew)

bashmacos
brew install faust

Windows

Baixa o instalador de faust.grame.fr/downloads. Inclui MSYS2 com os faust2* scripts.

Dependências dos scripts faust2*

Cada faust2vst, faust2lv2, etc. depende de SDKs externos: VST SDK da Steinberg, LV2 da Linux Audio Devs, CoreAudio da Apple. No primeiro uso pode pedir pra instalar. Vale ler o output do script — geralmente fala o que falta.

§ 03

faust2vst, faust2vst3.

VST é o formato padrão pra Windows. VST3 é a versão moderna (recomendado).

bashshell
# VST3 — recomendado, multiplataforma
faust2vst3 meu_compressor.dsp

# Pra plugin instrumento (synth polifônico do módulo 07)
faust2vst3 -nvoices 12 meu_synth.dsp

# Output: meu_compressor.vst3 (ou pasta .vst3 no macOS)

Instalar no DAW

SistemaCaminho VST3
WindowsC:\Program Files\Common Files\VST3\
macOS/Library/Audio/Plug-Ins/VST3/ ou ~/Library/Audio/Plug-Ins/VST3/
Linux~/.vst3/ ou /usr/lib/vst3/

Copia o arquivo (ou pasta .vst3) pra esse diretório, abre o DAW, força rescan dos plugins, e ele aparece.

§ 04

faust2lv2 (Linux).

LV2 é o padrão moderno do Linux (substitui o antigo LADSPA). Usado por Ardour, Carla, Qtractor, Mixbus, Reaper Linux.

bashshell
faust2lv2 meu_compressor.dsp

# Output: meu_compressor.lv2/ (pasta com .ttl manifest + .so binário)

Instalar:

bashshell
cp -r meu_compressor.lv2 ~/.lv2/

Abre Ardour → Mixer → New plugin → procura "meu_compressor". Tá lá.

§ 05

faust2au (macOS).

Audio Unit é o formato nativo do macOS. Usado por Logic, GarageBand, MainStage e qualquer DAW Mac.

bashshell
faust2au meu_compressor.dsp

# Instala em ~/Library/Audio/Plug-Ins/Components/
cp -r meu_compressor.component ~/Library/Audio/Plug-Ins/Components/

# Logic pode demorar pra reconhecer — vai em Logic Pro > Preferences > Plug-In Manager
# e clica em Reset & Rescan Selection
§ 06

faust2webaudio — plugin no browser.

Pra publicar seu plugin numa página web (demo, prototipagem rápida), use faust2webaudio.

bashshell
faust2webaudio meu_compressor.dsp

# Output: pasta com HTML + JS + WASM autônomos
# abre o index.html no navegador, plugin roda direto

Útil pra:

  • Demo público — hospeda no GitHub Pages, qualquer pessoa testa sem instalar nada.
  • Embed em site — coloca como widget na página, igual um SoundCloud.
  • Cliente testar antes do release — manda link, ele aprova sem precisar baixar VST.
§ 07

Distribuição — empacotar e publicar.

Plugin pronto. Como entregar pra outros operadores?

Free (open source)

  • GitHub release: cria um repo com o .dsp + binários compilados pra Win/Mac/Linux. Tag de versão, ZIP com tudo.
  • plugins4free.com, linuxaudio.org/freevsts: catálogos.
  • KVR Audio: o catálogo de plugins de áudio mais visitado. Cria entry, anuncia.

Pago

  • Plugin Boutique / Plugin Alliance: distribuidores grandes, comissão alta mas alcance enorme.
  • Gumroad: vende direto, comissão baixa, sem aprovação.
  • Site próprio: pagamento via Stripe ou PagSeguro, entrega via download link.
Licença

Sempre declara declare license "MIT" (ou outra) no .dsp. Pra plugin pago, geralmente proprietary. Pra colaborativo, MIT ou GPL. Inclui um LICENSE no repo.
