§ 01

Geradores no namespace os.

Em FAUST, qualquer oscilador é uma função que, sem input, devolve uma forma de onda. os. é o namespace de "oscillators" — vem com 30+ funções.

Os mais usados na prática:

FunçãoOndaUso típico
os.osc(f)senoidetom puro, oscilador de modulação (LFO)
os.sawtooth(f)dente de serrasintetizador analógico, bass
os.triangle(f)triangulartom suave, intermediário senoide/saw
os.square(f)quadradasom "chiptune", hollow
os.pulsetrain(f, duty)pulso PWMsíntese clássica de sintetizador
no.noiseruído brancomedição de sala, hi-hat, vento
no.pink_noiseruído rosamedição (mais natural), reference
Ruído rosa pra igreja

Pra medir a resposta da sala da igreja, o sinal padrão é ruído rosa: tem energia equivalente em cada oitava (igual ao que o ouvido percebe). Tocar ruído rosa do plugin no PA e medir com Open Sound Meter dá a curva de resposta da sala.

§ 02

os.osc — senoide pura.

O hello world do FAUST: senoide com slider de frequência.

senoide.dspfaust
declare name "Senoide pura";
import("stdfaust.lib");

freq = hslider("frequência [unit:Hz]", 440, 20, 20000, 1);
vol  = hslider("volume [unit:dB]", -12, -60, 0, 0.1) : ba.db2linear;

process = os.osc(freq) * vol <: _ , _;

Detalhes novos:

  • [unit:dB] nos metadados do slider faz o DAW mostrar como dB.
  • ba.db2linear converte o valor em dB pra ganho linear (porque * vol precisa ser linear).
  • : aplicado depois do hslider passa o output dele direto pro db2linear — sequencial em ação.
§ 03

os.sawtooth, os.triangle, os.square.

Trocando os.osc por uma dessas, você muda o timbre. Vamos fazer um plugin que deixa o usuário escolher.

multiwave.dspfaust
declare name "Multi-Wave Gen";
import("stdfaust.lib");

freq = hslider("frequência [unit:Hz]", 440, 20, 2000, 1);
vol  = hslider("volume", 0.3, 0, 1, 0.01);

// Seletor de onda: 0 = sine, 1 = saw, 2 = triangle, 3 = square
wave = nentry("forma [style:menu{'sine':0;'saw':1;'tri':2;'square':3}]", 0, 0, 3, 1);

// ba.selectn escolhe entre N entradas baseado num seletor
oscs = os.osc(freq), os.sawtooth(freq), os.triangle(freq), os.square(freq);

process = oscs : ba.selectn(4, wave) * vol <: _ , _;

O nentry com style:menu vira um dropdown no DAW. ba.selectn escolhe um dos 4 sinais com base no valor do wave.

§ 04

no.noise — ruído branco e rosa.

Ruído não tem frequência — é energia espalhada por todo o espectro. Útil pra teste de sistema, hi-hat, snare, vento, percussão.

noise.dspfaust
declare name "Ruído Tester";
import("stdfaust.lib");

vol  = hslider("volume [unit:dB]", -20, -60, 0, 0.1) : ba.db2linear;
tipo = nentry("tipo [style:menu{'branco':0;'rosa':1}]", 1, 0, 1, 1);

ruido = no.noise , no.pink_noise : ba.selectn(2, tipo);

process = ruido * vol <: _ , _;
Diferença prática

Branco soa "agudo demais" — energia igual por Hz, então acumula muito agudo. Rosa soa "neutro" — energia igual por oitava, o que casa com como o ouvido percebe. Pra medir e ouvir como referência, sempre rosa.

§ 05

Sliders e UI básica.

Catalogando os controles que viraram automáticos no DAW:

ControleVira no DAWUso
hslider("L", def, min, max, step)slider horizontalfrequência, volume, qualquer valor contínuo
vslider(...)slider verticalidem, layout vertical
nentry(...)entry numérica (ou dropdown)seletor de modo, presets
checkbox("L")checkboxbypass, on/off de seções
button("L")botão momentâneotrigger de envelope, panic
hbargraph("L", min, max)level meter horizontalmostrar output, gain reduction
vbargraph(...)level meter verticalidem, vertical

Metadata útil nos labels

  • [unit:Hz], [unit:dB], [unit:ms], [unit:%] — formatação.
  • [scale:log] — slider logarítmico (ideal pra frequência).
  • [style:knob] — vira knob em vez de slider (no Faust Editor; alguns DAWs honram).
  • [style:menu{'a':0;'b':1}] — dropdown.
  • [tooltip:texto] — dica de ajuda.
frequência logfaust
// slider de frequência com escala logarítmica — natural pra ouvido
freq = hslider("frequência [unit:Hz][scale:log][tooltip:freq da nota]",
              440, 20, 20000, 0.1);
§ 06

Aplicação: gerador de tom de teste.

Plugin prático: tester completo de PA. Senoide pra testar grave/médio/agudo, ruído rosa pra medir resposta da sala, botão de mute pra cortar rapidamente.

tester.dspfaust
declare name "Tester PA — Igreja";
declare author "Jefferson Cunha";
import("stdfaust.lib");

// Fonte: 0 = senoide, 1 = ruído rosa
fonte = nentry("fonte [style:menu{'senoide':0;'ruído rosa':1}]", 0, 0, 1, 1);

// Frequência da senoide (log, pra cobrir 20 Hz a 20 kHz com curva natural)
freq = hslider("frequência [unit:Hz][scale:log]", 1000, 20, 20000, 1);

// Volume em dB pra não estourar
vol = hslider("volume [unit:dB]", -20, -60, 0, 0.1) : ba.db2linear;

// Mute pra cortar rápido (checkbox: 0 toca, 1 muta)
mute = checkbox("mute");

// Soma das duas fontes selecionadas
sinal = os.osc(freq) , no.pink_noise : ba.selectn(2, fonte);

process = sinal * vol * (1 - mute) <: _ , _;

Isso é um plugin completo. Pluga no Reaper, abre no master, e você tem: tom de teste com slider de frequência (pra varrer e identificar ressonâncias), ruído rosa pra medir, e mute imediato.

Roteiro de uso no culto

(1) Abre o tester como insert no master. (2) Toca ruído rosa em -20 dB. (3) Sai no templo com o medidor (Open Sound Meter). (4) Identifica picos/vales na resposta. (5) Volta pro tester, troca pra senoide e varre as frequências críticas pra confirmar. (6) Aperta mute, fecha o plugin.

Glossário rápido
os.osc(f)
Senoide pura na frequência f.
os.sawtooth(f)
Dente de serra. Rico em harmônicos.
os.square(f)
Onda quadrada. Só harmônicos ímpares.
no.noise
Ruído branco. Energia igual por Hz.
no.pink_noise
Ruído rosa. Energia igual por oitava.
ba.db2linear(x)
Converte dB pra ganho linear (10^(x/20)).
ba.selectn(N, idx)
Seleciona 1 entre N sinais paralelos.
nentry(...)
Entrada numérica. Vira dropdown com [style:menu].
checkbox("L")
Vira on/off no DAW.
[unit:Hz]
Metadado de unidade — formata como "440 Hz".
[scale:log]
Slider logarítmico — natural pra frequência.
