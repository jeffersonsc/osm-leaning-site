Módulo 06 — UI

UI: sliders, grupos, meters.

Plugin com lógica boa e UI bagunçada é plugin que ninguém usa. Aqui você aprende a organizar controles em grupos, mostrar meters, customizar com metadata, e fazer o teu plugin parecer profissional no DAW.

§ 01

Primitivas de UI — referência completa.

FunçãoTipo de controleUso
hslider("L", def, min, max, step)slider horizontaltodo valor contínuo
vslider(...)slider verticalidem (escolha por layout)
nentry("L", def, min, max, step)spinner numéricoBPM, número de vozes, preset index
button("L")botão momentâneotrigger, reset, panic
checkbox("L")checkboxbypass, on/off de seções
hbargraph("L", min, max)meter horizontaloutput level, gain reduction
vbargraph("L", min, max)meter verticalidem, layout vertical

Os 4 controles de entrada (slider, nentry, button, checkbox) retornam sinais que você multiplica/usa no DSP. Os 2 meters (hbargraph, vbargraph) recebem um sinal e mostram visualmente.

§ 02

Metadata: unit, scale, style, tooltip.

Dentro do label do controle (entre [ ]) você adiciona metadata que customiza como ele aparece. Várias chaves disponíveis:

MetadataEfeito
[unit:Hz]DAW formata como "440 Hz"
[unit:dB]formata como "-12 dB"
[unit:ms]"100 ms"
[unit:%]"35 %"
[scale:log]slider logarítmico (essencial pra frequência)
[scale:exp]slider exponencial
[style:knob]vira knob ao invés de slider (no Faust IDE; alguns DAWs honram)
[style:menu{'a':0;'b':1}]nentry vira dropdown
[style:radio{'a':0;'b':1}]nentry vira radio buttons
[tooltip:texto]dica ao hover
[hidden:1]esconde no UI mas mantém parametrizável via OSC/MIDI
[midi:ctrl 1]mapeia pro controller MIDI 1
metadata.dspfaust
declare name "Filtro com metadata";
import("stdfaust.lib");

// Slider de freq com tudo: log + Hz + tooltip + MIDI
freq = hslider("frequência [unit:Hz][scale:log][tooltip:freq do filtro][midi:ctrl 74]",
              1000, 20, 20000, 1);

vol = hslider("volume [unit:dB][style:knob]", -12, -60, 0, 0.1);

process = fi.lowpass(2, freq) : *(vol : ba.db2linear);
§ 03

Grupos: hgroup, vgroup, tgroup.

3 controles soltos viram 3 sliders empilhados. 9 controles soltos viram bagunça. Use hgroup (horizontal), vgroup (vertical) ou tgroup (tabs) pra organizar.

grupos.dspfaust
declare name "Grupos via prefixo";
import("stdfaust.lib");

// Grupo "low" — prefixo "low/" no label coloca os 2 sliders juntos
low_freq = hslider("low/freq [unit:Hz][scale:log]", 100, 20, 500, 1);
low_gain = hslider("low/gain [unit:dB]", 0, -18, 18, 0.1);

// Grupo "mid" — prefixo "h:" força hgroup horizontal explícito
mid_freq = hslider("h:mid/freq [unit:Hz][scale:log]", 1000, 200, 5000, 1);
mid_gain = hslider("h:mid/gain [unit:dB]", 0, -18, 18, 0.1);

// EQ peak em cada banda — usa os 4 sliders pra UI aparecer no DAW
q = 1.0;
process = fi.peak_eq(low_gain, low_freq, q) : fi.peak_eq(mid_gain, mid_freq, q);

Forma prática (prefixo) — mais usada

Adicionar "grupo/nome" no label do slider automaticamente coloca ele no grupo. Forma mais legível pra plugin simples.

eq_groups.dspfaust
declare name "EQ 3 bandas paramétrico";
import("stdfaust.lib");

// 3 grupos: low, mid, high. Cada um com freq + gain (prefixo "X/" no label).
low_freq  = hslider("low/freq [unit:Hz][scale:log]", 100, 20, 500, 1);
low_gain  = hslider("low/gain [unit:dB]", 0, -18, 18, 0.1);
mid_freq  = hslider("mid/freq [unit:Hz][scale:log]", 1000, 200, 5000, 1);
mid_gain  = hslider("mid/gain [unit:dB]", 0, -18, 18, 0.1);
high_freq = hslider("high/freq [unit:Hz][scale:log]", 8000, 2000, 20000, 1);
high_gain = hslider("high/gain [unit:dB]", 0, -18, 18, 0.1);

q = 1.0;

// Cadeia série dos 3 EQs — UI aparece como 3 colunas (low | mid | high)
process = fi.peak_eq(low_gain,  low_freq,  q)
        : fi.peak_eq(mid_gain,  mid_freq,  q)
        : fi.peak_eq(high_gain, high_freq, q);

Tabs com tgroup

Pra plugins grandes, organize em tabs. Aparece como abas no Faust IDE.

tabs.dspfaust
declare name "EQ + Compressor (tabs)";
import("stdfaust.lib");

// Tab "EQ" — prefixo "t:EQ/" coloca os 2 sliders na aba EQ
eq_low  = hslider("t:EQ/low [unit:dB]",  0, -18, 18, 0.1);
eq_high = hslider("t:EQ/high [unit:dB]", 0, -18, 18, 0.1);

// Tab "Compressor"
comp_ratio  = hslider("t:Compressor/ratio", 4, 1, 20, 0.1);
comp_thresh = hslider("t:Compressor/threshold [unit:dB]", -18, -60, 0, 0.1);

// Cadeia: low shelf -> high shelf -> compressor
eq   = fi.low_shelf(eq_low, 200) : fi.high_shelf(eq_high, 5000);
comp = co.compressor_mono(comp_ratio, comp_thresh, 0.01, 0.1);

process = eq : comp;

Prefixo h: = hgroup, v: = vgroup, t: = tgroup. Sem prefixo, é default da plataforma.

§ 04

Meters de saída e gain reduction.

Plugin profissional sempre mostra o que está acontecendo. Mínimo: output level meter pra evitar clip. Compressor: gain reduction meter.

meters.dspfaust
declare name "Compressor com meters";
import("stdfaust.lib");

// Controles do compressor (grupo "comp")
ratio   = hslider("comp/ratio", 4, 1, 20, 0.1);
thresh  = hslider("comp/threshold [unit:dB]", -18, -60, 0, 0.1);
attack  = 0.01;
release = 0.1;

// gr_meter: recebe ganho linear (0..1), passa adiante e mostra em dB
gr_meter(g) = attach(g, g : ba.linear2db : hbargraph("meters/redução [unit:dB]", -24, 0));

// out_meter: recebe sinal, passa adiante e mostra o pico em dB (abs pra ficar positivo)
out_meter(s) = attach(s, s : abs : ba.linear2db : hbargraph("meters/output [unit:dB]", -60, 0));

// Plugin: aplica o ganho do compressor e exibe os 2 meters
process(x) = x * (x : co.compression_gain_mono(ratio, thresh, attack, release) : gr_meter) : out_meter;
attach é o segredo

attach(a, b) = "passa a adiante, e use b só pra side-effects (meter, log, debug)". Sem attach, o meter "consome" o sinal e o áudio quebra.

§ 05

Presets via declare.

Plugin profissional vem com presets. FAUST não tem sistema de presets nativo, mas você pode:

  1. Salvar os valores dos sliders como declare metadata.
  2. O export pra VST3 (módulo 08) inclui o preset default.
  3. Pro DAW gerenciar presets, ele lê o preset salvo no plugin XML.
plugin com metadatafaust
declare name        "Vocal Compressor";
declare author      "Jefferson Cunha";
declare version     "1.0";
declare license     "MIT";
declare copyright   "2026 Jefferson Cunha";
declare description "Compressor de voz pra mic dinâmico de pregador";
declare category    "Dynamics";

Esses metadados aparecem no About do plugin no DAW. category em particular ajuda o DAW a organizar o plugin no menu (Dynamics, EQ, Reverb, etc.).

§ 06

Boas práticas de UI.

  1. Use [scale:log] em freq — sliders lineares são inúteis pra frequência. 100 Hz e 200 Hz devem estar igualmente separados de 200 Hz e 400 Hz.
  2. dB pra ganho, ms pra tempo — sempre. Linear em ganho é confuso. Segundos pra delay também — use ms.
  3. Defaults razoáveis — o slider deve abrir num valor útil. Threshold de compressor não abre em 0 dB.
  4. Step apropriado — 0.01 dB pra ganho fino, 1 Hz pra freq, 0.1 pra ratio.
  5. Agrupe por função — todos os controles do compressor num grupo "comp/", todos do EQ em "eq/".
  6. Meter no final — coloca o output meter sempre como último parâmetro pro DAW exibir no final.
  7. Tooltip nos não-óbvios — "feedback" sozinho não diz nada; [tooltip:nível de repetição do delay] sim.
Anti-pattern comum

10 sliders soltos sem grupo nem unit. No DAW vira uma lista de "param 1, param 2..." que ninguém entende. Sempre use grupos e units — leva 5 caracteres a mais por slider e muda completamente a experiência.

vgroup("nome", expr)
