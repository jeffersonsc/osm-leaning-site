Transfer function

magnitude + phase + coherence
are one thing

All three together or none.

Transfer function is the mathematical comparison between what went in the system (generator signal, via loopback) and what came out (signal picked up by the mic). It has 3 outputs that must be read together:

Magnitude:
HOW MUCH the system changed each frequency (in dB).
Phase:
HOW MUCH the system delayed each frequency (in degrees).
Coherence:
HOW TRUSTWORTHY the two above are (0 to 1).
✓ How to enable in OSM
Cmd/Ctrl + 3 opens 3 graphs side by side
In each one choose Magnitude / Phase / Coherence
FFT power 14, LPF 1 Hz standard for churches / rooms
Coherence threshold 0.7 automatically hides bad data
Magnitude (dB) +10 / 0 / −30
Phase (degrees) +180 / 0 / −180
Coherence (0–1) 20 Hz — 1 kHz — 20 kHz
Reading order when interpreting
1
Coherence
Look first. Where it's low, ignore the other two.
2
Phase
Smooth or decreasing = ok. Abrupt jumps = problem (or wrap, see inf. 01).
3
Magnitude
General trend, peaks and notches — but only where coherence is good.
