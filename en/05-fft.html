FFT window and resolution

choose the right size
for each measurement type

Speed or detail.

FFT transforms a time signal into a frequency signal. The size of the time window it uses defines a trade-off:

Short window (low power)

Responds fast to changes, but frequency resolution is poor — many hertz between each point. Good for seeing live feedback.

Long window (high power)

Fine resolution (fractions of a hertz), but slow response. At low frequencies, still captures room reflections. Good for measuring speakers in a quiet room.

Logarithmic window

Uses 24 different windows — one per frequency band. It's the best of all, but uses more CPU. Use it when you can.

⚠ Common pitfall

"The longer the window, the better the measurement" — WRONG.

A long window captures the direct sound + all room reflections. In reverberant environments, this messes up the bass reading instead of improving it.

If the room is reverberant, start with power 14. Only go higher if coherence in the bass is solid.
